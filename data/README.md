# Data notes

`raw/` contains the project snapshot used by the training notebook and `src/train.py`:

- `COSING_Ingredients-Fragrance Inventory_v2.csv` — ingredient records used by the training script.
- `COSING_Annex_II_v2.xls` through `COSING_Annex_V_v2.xls` — supporting annex snapshots.
- `COSING_Annexes.pdf` — reference material retained with the project data.

The source is the European Commission's CosIng (Cosmetic Ingredients) information. These files are retained to make the student research workflow inspectable and reproducible. They are not a claim of ownership or a guarantee that this snapshot is current. Verify the current authoritative source, data terms, and any redistribution requirements before using this data elsewhere.
